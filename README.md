# حصون الحفظ

تطبيق أندرويد ينظّم جدولك اليومي لحفظ القرآن الكريم ومراجعته بطريقة **الحصون الخمسة** وبطرق أخرى،
ومعه أدوات تعين الحافظ أثناء الحفظ والمراجعة. يعمل دون إنترنت، وكل بياناتك تبقى على جهازك.

## تنزيل التطبيق (APK)

كل رفع للكود يبني ملف APK تلقائيًا:

1. افتح تبويب **Actions** في المستودع، ثم آخر تشغيل ناجح لـ **Build APK**.
2. من قسم **Artifacts** نزّل `husoon-alhifz-apk` وفكّ الضغط عنه.
3. انقل `husoon-alhifz.apk` إلى هاتفك وثبّته (اسمح بالتثبيت من مصادر غير معروفة). يتطلب أندرويد 8 فأحدث.

## الطرق المدعومة

| الطريقة | أورادها اليومية |
|---|---|
| **الحصون الخمسة** | التلاوة والاستماع · التحضير (الأسبوعي والليلي والقبلي) · الحفظ الجديد · مراجعة القريب · مراجعة البعيد |
| **السبق والسبقي والمنزل** | درس جديد · مراجعة الدروس الأخيرة · ورد من المحفوظ القديم |
| **التكرار والربط** | تكرار كل آية ثم ربط كل أربع آيات ثم ربط المقطع، مع مراجعة القريب والبعيد |
| **التكرار المتباعد** | كل مقطع يعود للمراجعة بعد يوم ثم ٣ ثم ٧ ثم ١٤ ثم ٣٠ يومًا… بحسب إتقانك |
| **تثبيت الخاتم (فمي بشوق)** | ختمة مراجعة كل أسبوع على تحزيب السلف مع ورد استماع |
| **خطة مخصصة** | تختار الأوراد ومقاديرها بنفسك |

الجدول يتقدّم بإنجازك لا بالتقويم: إن فاتك يوم لم تتراكم عليك الأوراد، بل تكمل من حيث وقفت.
مقدار الحفظ (ربع صفحة إلى خمس صفحات)، واتجاهه (من الفاتحة، أو من جزء عمّ نزولًا، أو من الناس صعودًا)،
وأيام الحفظ، ومقادير كل ورد — كلها قابلة للتعديل.

## الأدوات

- **المصحف**: نص عثماني برواية حفص (٦٠٤ صفحات)، إخفاء النص للتسميع (كاملًا أو مع إبقاء أول كلمة)، تظليل مقطع الورد، فهرس بالسور والأجزاء والصفحات.
- **سمِّع وسجّل**: تسجيل صوتي لتلاوتك أثناء التسميع، ثم تستمع له والنص أمامك لتكتشف أخطاءك.
- **جلسة التكرار والربط** و**عدّاد التكرار** مع اهتزاز عند بلوغ العدد.
- **الاستماع والترديد**: قرّاء متقنون، تكرار الآية والمقطع، ومهلة للترديد خلف القارئ (يحتاج إنترنت).
- **اختبر حفظك**: أكمل ما بعد الآية، والخطأ يُضاف تلقائيًا إلى مواضع المراجعة.
- **مواضع الخطأ والمتشابهات**، و**مؤقّت التركيز**، و**دليل الطرق**.
- **دفتري**: ملاحظات مصنّفة (تدبّر، تفسير، متشابهات…) قابلة للربط بآية، وتسجيلاتك الصوتية، ومكتبة ملفات (تفسير وتجويد وغيرها: PDF وصور ونصوص وصوتيات) تُقرأ داخل التطبيق.
- **التقدّم والتحفيز**: أيام المواظبة المتتالية، خريطة الأجزاء، خريطة المواظبة، موعد الختم المتوقع، أوسمة، وتنبيهات يومية.
- نسخ احتياطي واستيراد، ووضع داكن.

## البنية

```
app/src/main/assets/www/   واجهة التطبيق (HTML/CSS/JS دون مكتبات خارجية)
  js/plan.js               منطق الطرق وجدولة الأوراد
  data/quran.js            نص المصحف وفهرس الصفحات (يولَّد بـ tools/build-data.mjs)
app/src/main/java/         غلاف أندرويد: WebView، الميكروفون، الملفات، التنبيهات
tools/                     توليد البيانات واختبار الجدولة (node tools/test-plan.cjs)
```

البناء محليًا: `./gradlew assembleRelease` (يتطلب Android SDK 34 و JDK 17).

> مفتاح التوقيع في `keystore/` موضوع في المستودع عمدًا ليمكن تحديث التطبيق فوق نسخته السابقة، وهو **غير سرّي**؛ استبدل به مفتاحك الخاص قبل النشر في أي متجر.

## المصادر والحقوق

- نص المصحف: الرسم العثماني برواية حفص من «موسوعة القرآن الكريم» [QuranEnc.com](https://quranenc.com) عبر حزمة [quran-json](https://github.com/risan/quran-json) (CC BY 4.0)، منسوخ دون أي تعديل.
- خط المصحف: KFGQPC HAFS Uthmanic Script — مجمع الملك فهد لطباعة المصحف الشريف (مرخّص للاستخدام والتوزيع المجاني دون تعديل).
- فهرس الصفحات والأجزاء: [quran-meta](https://www.npmjs.com/package/quran-meta) (MIT). خط الواجهة: Tajawal (OFL). عرض PDF: [PDF.js](https://mozilla.github.io/pdf.js/) (Apache-2.0). التلاوات: [EveryAyah.com](https://everyayah.com).

مقادير الأوراد في كل طريقة اجتهادية وقابلة للتعديل؛ فخذ منها ما يناسب طاقتك، واستشر شيخك.
